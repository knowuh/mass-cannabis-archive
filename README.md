# Massachusetts Cannabis Data Archive

A version-controlled repository tracking the evolution of the MA cannabis market. This project snapshots public data from the Cannabis Control Commission (CCC) to provide a longitudinal history of licenses, ownership, and pricing.

## 🛠 Project Mission
- **Transparency:** Tracking the shift from independent "Mom & Pop" shops to Multi-State Operators (MSOs).
- **Public Record:** Providing a permanent archive of CCC datasets that are otherwise overwritten during updates.
- **Open Access:** All data is provided in raw JSON/CSV formats for researchers and journalists.

## 📂 Data Structure
- `/data/ccc/`: Weekly snapshots of the CCC Application and License database.
- `/data/pricing/`: Historical retail price averages for Western MA.
